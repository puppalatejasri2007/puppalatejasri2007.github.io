# Puppala Tejasri Portfolio

## Run in VS Code

### 1. Open the project
Open this folder in VS Code.

### 2. Start backend
Open a terminal:

```bash
cd backend
npm install
npm start
```

Backend:
http://localhost:5000

### 3. Start frontend
Install the VS Code "Live Server" extension if you do not already have it.

Right-click:

frontend/index.html

Then choose:

Open with Live Server

The frontend will normally open at:
http://127.0.0.1:5500

Keep the backend terminal running while using the website.

## Test backend

Open:
http://localhost:5000

Then:
http://localhost:5000/api/profile

## Contact form

The contact form sends POST requests to:
http://localhost:5000/api/contact

At this stage, messages are printed in the backend terminal and are not permanently stored.
